# ✈️ TravelEase - Tour Booking System

**Live Website:** [my-travelease.great-site.net](http://my-travelease.great-site.net)

A dynamic, web-based Tour Booking System built with PHP and MySQL. It allows users to browse packages, book flights, hotels, and cabs, while providing a full admin dashboard for managing bookings and revenue.

## 🚀 Features
- User Authentication (Login/Register)
- Dynamic Package Search & Filtering
- Multi-Service Booking (Flight, Train, Hotel, Cab)
- Secure Checkout & Payment Simulation
- Admin Dashboard (CRUD operations for Packages, Bookings, Payments)

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript
- **Backend:** PHP
- **Database:** MySQL

## 💻 Local Setup
1. Clone the repo: `git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git`
2. Move the folder to your XAMPP `htdocs` directory.
3. Import the database (`travelease_db.sql`) into phpMyAdmin.
4. Update `database.php` with your local database credentials.
